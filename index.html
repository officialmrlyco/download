Download APK - v1.3.5

Android may ask you to allow installation from this browser before opening the APK. Only install from this official Bingwa Flash link.

After downloading

  1. Open the APK from your Downloads folder and allow install from this source if Android asks.
  2. Enable the required SMS, phone and accessibility permissions only for the automation features you use.
  3. Set your offers, SIM choice, USSD mappings, retry rules and web order settings before going live.

Requirements

  • Android 7.0 or higher.
  • Safaricom SIM and stable network access.
  • SMS, phone and accessibility permissions for enabled automation.
  • Internet access for account sync, web orders and support tools.
